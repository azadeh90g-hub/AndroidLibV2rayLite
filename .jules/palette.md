## 2025-05-15 - Actionable Error Messages for Developer Experience
**Learning:** In headless libraries or SDKs, the "User Interface" is the API and its error messages. Providing actionable error messages (e.g., "call X before Y") significantly improves the Developer Experience (DX) by reducing frustration and debugging time.
**Action:** When an error occurs due to an invalid state or missing initialization, always suggest the specific method or step required to resolve it.
