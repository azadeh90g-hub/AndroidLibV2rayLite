## 2025-05-15 - DX as UX in Libraries
**Learning:** For library projects, User Experience (UX) is best interpreted as Developer Experience (DX). This includes providing actionable error messages, maintaining accurate build documentation, and ensuring helper scripts provide clear feedback (like progress bars) and usage guidance.
**Action:** When working on non-UI projects, audit the onboarding flow (README), common error paths, and script outputs for potential "micro-UX" improvements.
