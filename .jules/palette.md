## 2025-01-31 - [Developer Experience as UX]
**Learning:** For library projects without a traditional UI, User Experience (UX) is primarily represented by Developer Experience (DX). This includes actionable error messages, robust setup scripts, and clear documentation.
**Action:** When working on libraries, look for "dead ends" in the developer journey (e.g., cryptic errors, failing scripts due to missing directories) and smooth them out.

## 2025-01-31 - [Workspace Hygiene]
**Learning:** Automatic generation of assets should be paired with proper `.gitignore` updates. Ensuring that large, generated binary files don't clutter the git history is a key UX improvement for developers contributing to the repo.
**Action:** Always check if new generated directories or files are appropriately ignored by version control.
