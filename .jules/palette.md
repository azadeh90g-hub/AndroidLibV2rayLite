## 2025-05-14 - Developer Onboarding Experience

**Learning:** For developer-focused libraries, the "User Experience" is synonymous with "Developer Experience" (DX). Clear, complete, and verified build instructions are the most critical UX element. Small touches like progress bars in setup scripts provide essential feedback and reduce the perceived "friction" of getting started.

**Action:** Always verify that build instructions in the README are complete and that any external asset dependencies are handled gracefully with robust, feedback-rich scripts. Ensure that any downloaded assets are properly excluded via `.gitignore` to prevent repository bloat.
