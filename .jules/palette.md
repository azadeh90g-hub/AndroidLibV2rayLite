## 2025-02-04 - DX as UX for Libraries
**Learning:** For non-UI projects like libraries, 'User Experience' (UX) is effectively 'Developer Experience' (DX). Improving onboarding scripts, build instructions, and providing visual feedback (like progress bars) for long-running CLI tasks significantly improves the perceived quality and usability of the project.
**Action:** Always look for silent, slow-running scripts and add progress indicators. Ensure build instructions are complete and match the actual required steps.
